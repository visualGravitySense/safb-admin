# Руководство по безопасности Dashboard

## Учетные данные администратора

### Настройка пароля

По умолчанию используется сложный пароль: `SAFunk2024!Admin#Secure`

**ВАЖНО**: Для production обязательно измените пароль!

### Как изменить пароль

1. Создайте файл `.env` в папке `dashboard` (на основе `.env.example`)
2. Установите свои значения:

```env
VITE_ADMIN_USERNAME=your_username
VITE_ADMIN_PASSWORD=your_strong_password
```

3. Перезапустите Dashboard

### Требования к паролю

Рекомендуется использовать пароль, который:
- Минимум 12 символов
- Содержит заглавные и строчные буквы
- Содержит цифры
- Содержит специальные символы (!@#$%^&*)
- Не является словарным словом
- Не содержит личную информацию

### Примеры надежных паролей

- `SAFunk2024!Admin#Secure` (текущий по умолчанию)
- `MyBand@2024#Dashboard!Admin`
- `SAFunkBand$Admin2024!Secure`

### Безопасность

⚠️ **ВАЖНО для production:**

1. **Никогда не коммитьте `.env` файл в Git**
   - Файл `.env` уже добавлен в `.gitignore`
   - Используйте `.env.example` как шаблон

2. **Используйте разные пароли для разных окружений**
   - Development: можно использовать простой пароль
   - Production: обязательно сложный уникальный пароль

3. **Регулярно меняйте пароль**
   - Рекомендуется менять каждые 3-6 месяцев

4. **Ограничьте доступ к Dashboard**
   - Используйте VPN или firewall
   - Ограничьте доступ по IP адресу
   - Используйте HTTPS в production

5. **Мониторинг доступа**
   - Следите за логами входа
   - Настройте уведомления о подозрительной активности

### Дополнительные меры безопасности

В будущем рекомендуется:
- Добавить двухфакторную аутентификацию (2FA)
- Реализовать rate limiting для попыток входа
- Добавить логирование всех действий
- Использовать JWT токены вместо localStorage
- Реализовать сессии с автоматическим выходом

### Текущая реализация

Текущая система аутентификации является упрощенной и подходит для:
- ✅ Разработки и тестирования
- ✅ Внутреннего использования
- ❌ НЕ подходит для публичного production сайта

Для production рекомендуется:
- Интеграция с OAuth (Google, GitHub)
- Использование JWT с refresh tokens
- Backend аутентификация с хешированием паролей (bcrypt)
- Защита от brute force атак

## Восстановление доступа

Если вы забыли пароль:

1. Проверьте файл `.env` в папке `dashboard`
2. Если файла нет, используйте пароль по умолчанию: `SAFunk2024!Admin#Secure`
3. Очистите localStorage в браузере (F12 → Application → Local Storage → удалите ключ `auth`)

## Контакты

При проблемах с доступом обратитесь к администратору системы.
