# Troubleshooting Guide

## Common Errors and Solutions

### "A listener indicated an asynchronous response by returning true, but the message channel closed before a response was received"

**Причина:**
Эта ошибка обычно связана с расширениями браузера (например, блокировщики рекламы, расширения для разработчиков, VPN и т.д.), которые пытаются перехватывать сообщения между страницей и расширением.

**Решение:**
1. **Это не критическая ошибка** - она не влияет на функциональность приложения
2. Если ошибка мешает работе:
   - Отключите расширения браузера по одному, чтобы найти виновника
   - Попробуйте использовать режим инкогнито (расширения обычно отключены)
   - Попробуйте другой браузер
3. В коде уже добавлена обработка ошибок для всех async операций

**Технические детали:**
- Ошибка возникает, когда расширение браузера пытается перехватить сообщение, но не отвечает вовремя
- Это не ошибка вашего кода, а особенность работы расширений браузера
- Все async функции в приложении теперь имеют обработку ошибок

### Другие распространенные проблемы

#### Ошибки загрузки файлов
- Убедитесь, что API сервер запущен на порту 3000
- Проверьте, что файл не превышает 10MB
- Убедитесь, что файл является изображением (jpg, png, gif, webp)

#### Ошибки сохранения данных
- Проверьте консоль браузера для подробностей
- Убедитесь, что API сервер доступен
- Проверьте, что данные в правильном формате

#### Проблемы с отображением изображений
- Убедитесь, что изображения загружены через API
- Проверьте URL изображений в консоли браузера
- Убедитесь, что API сервер может отдавать статические файлы из `/uploads`

## Получение помощи

Если проблема не решена:
1. Проверьте консоль браузера (F12) для подробных ошибок
2. Проверьте логи API сервера
3. Убедитесь, что все зависимости установлены (`npm install`)
4. Перезапустите серверы (API и Dashboard)
