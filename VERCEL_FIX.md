# Исправление проблемы 404 на Vercel

## Проблема

При обращении к `https://safb-admin.vercel.app/api/health` получаете ошибку `404: NOT_FOUND`.

## Причины

1. Vercel может деплоить проект как статический сайт (Vue приложение), а не как serverless function
2. Неправильная конфигурация роутинга
3. Неправильный формат экспорта для Vercel

## Решение

### Вариант 1: Проверьте Root Directory в Vercel

1. Зайдите в Vercel Dashboard
2. Откройте ваш проект `safb-admin`
3. Settings → General → Root Directory
4. Убедитесь, что указано: `dashboard`
5. Сохраните и передеплойте

### Вариант 2: Создайте отдельный проект для API

Если Vercel продолжает деплоить Vue приложение:

1. Создайте новый проект в Vercel
2. Назовите его, например, `safb-api`
3. Укажите Root Directory: `dashboard`
4. В настройках проекта добавьте:
   - **Framework Preset**: Other
   - **Build Command**: (оставьте пустым)
   - **Output Directory**: (оставьте пустым)
5. Деплойте

### Вариант 3: Используйте правильную структуру файлов

Убедитесь, что структура такая:

```
dashboard/
├── api/
│   └── index.js      ← Должен экспортировать handler
├── vercel.json       ← Конфигурация
└── package.json      ← Зависимости
```

### Вариант 4: Проверьте Build Logs

1. В Vercel Dashboard откройте ваш деплой
2. Нажмите "Build Logs"
3. Проверьте, что:
   - `api/index.js` обнаружен
   - Нет ошибок при сборке
   - Serverless function создан

## После исправления

1. Передеплойте проект:
   ```bash
   cd dashboard
   vercel --prod
   ```

2. Проверьте API:
   ```bash
   curl https://safb-admin.vercel.app/api/health
   ```

3. Должен вернуться JSON ответ вместо 404.

## Альтернативное решение: Отдельный репозиторий для API

Если проблемы продолжаются, создайте отдельный минимальный проект только для API:

1. Создайте новую папку `api-vercel/`
2. Скопируйте туда:
   - `api/index.js`
   - `vercel.json`
   - `package.json` (только с зависимостями для API)
3. Задеплойте этот проект отдельно

Это гарантирует, что Vercel будет деплоить только API, а не Vue приложение.
