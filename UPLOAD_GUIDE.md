# Руководство по загрузке изображений

## Обзор

Dashboard поддерживает загрузку изображений для:
- **Gallery** - фотографии для галереи
- **About / Members** - фото участников бэнда

## Как использовать

### Загрузка изображения в Gallery

1. Откройте раздел **Gallery** в Dashboard
2. Нажмите **Add Image**
3. В диалоге нажмите **Upload Image**
4. Выберите файл изображения (jpg, png, gif, webp)
5. После загрузки изображение автоматически появится в форме
6. Заполните остальные поля (Title, Category, Views, Likes)
7. Нажмите **Save**

### Загрузка фото участника

1. Откройте раздел **About / Members**
2. Нажмите **Add Member** или **Edit** у существующего участника
3. В поле **Photo** нажмите **Upload Photo**
4. Выберите файл изображения
5. После загрузки фото появится в форме
6. Заполните остальные поля
7. Нажмите **Save**

## Технические детали

### Поддерживаемые форматы
- JPEG / JPG
- PNG
- GIF
- WebP

### Ограничения
- Максимальный размер файла: **10MB**
- Изображения сохраняются в `server/uploads/`
- URL загруженных файлов: `/uploads/filename.jpg`

### API Endpoints

#### Загрузка изображения
```
POST /api/upload
Content-Type: multipart/form-data

Body:
  image: [file]
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "url": "/uploads/image-1234567890-123456789.jpg",
    "filename": "image-1234567890-123456789.jpg",
    "originalName": "photo.jpg",
    "size": 123456,
    "mimetype": "image/jpeg"
  }
}
```

#### Удаление изображения
```
DELETE /api/upload/:filename
```

**Ответ:**
```json
{
  "success": true,
  "message": "File deleted successfully"
}
```

## Хранение файлов

Загруженные изображения сохраняются в:
```
dashboard/server/uploads/
```

Файлы доступны по URL:
```
http://localhost:3000/uploads/filename.jpg
```

## Использование URL вместо загрузки

Вы также можете использовать внешние URL или пути к существующим изображениям:

1. В поле загрузки оставьте поле пустым
2. Введите URL в текстовое поле ниже
3. Поддерживаются:
   - Полные URL: `https://example.com/image.jpg`
   - Локальные пути: `/uploads/image.jpg`
   - Относительные пути: `../img/photo.jpg`

## Интеграция с основным сайтом

Для использования загруженных изображений на основном React сайте:

### Вариант 1: Копировать файлы
Скопируйте файлы из `dashboard/server/uploads/` в `SAFunkBand/src/img/` или `SAFunkBand/public/img/`

### Вариант 2: Использовать API
В React приложении используйте URL:
```javascript
const imageUrl = `http://localhost:3000${item.image}`
```

### Вариант 3: Экспорт данных
Экспортируйте данные из Dashboard вместе с путями к изображениям и используйте их в React приложении.

## Безопасность

⚠️ **Важно для production:**

1. **Валидация файлов:**
   - Проверка типа файла
   - Проверка размера
   - Проверка содержимого (не только расширения)

2. **Ограничение доступа:**
   - Добавьте аутентификацию для endpoint `/api/upload`
   - Ограничьте размер файлов
   - Ограничьте типы файлов

3. **Хранение:**
   - Рассмотрите использование облачного хранилища (AWS S3, Cloudinary)
   - Настройте резервное копирование
   - Ограничьте доступ к папке uploads

4. **Очистка:**
   - Регулярно удаляйте неиспользуемые файлы
   - Настройте автоматическую очистку старых файлов

## Устранение проблем

### Изображение не загружается
- Проверьте размер файла (максимум 10MB)
- Убедитесь, что формат поддерживается
- Проверьте консоль браузера на ошибки
- Проверьте консоль API сервера

### Изображение не отображается
- Убедитесь, что API сервер запущен
- Проверьте URL изображения
- Проверьте, что файл существует в `server/uploads/`
- Проверьте права доступа к файлу

### Ошибка "File too large"
- Уменьшите размер изображения
- Используйте сжатие изображений
- Или увеличьте лимит в `server/index.js` (строка 36)
