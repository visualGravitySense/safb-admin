# Руководство по настройке Dashboard

## Что было создано

Создан полнофункциональный Dashboard на Vue.js + Vite для управления контентом сайта Siim Aimla Funk Band.

## Структура проекта

```
dashboard/
├── src/
│   ├── views/
│   │   ├── Login.vue              # Страница входа
│   │   ├── Dashboard.vue          # Главная страница дашборда
│   │   └── content/
│   │       ├── Hero.vue           # Управление Hero секцией
│   │       ├── About.vue           # Управление About и участниками
│   │       ├── Events.vue          # Управление событиями
│   │       ├── Music.vue           # Управление музыкой
│   │       ├── Gallery.vue         # Управление галереей
│   │       ├── Stats.vue           # Управление статистикой
│   │       └── Booking.vue         # Настройки бронирования
│   ├── layouts/
│   │   └── DashboardLayout.vue    # Основной layout с навигацией
│   ├── stores/
│   │   ├── auth.js                # Store для аутентификации
│   │   └── content.js             # Store для управления контентом
│   ├── router/
│   │   └── index.js               # Роутинг приложения
│   ├── App.vue                    # Корневой компонент
│   └── main.js                    # Точка входа
├── index.html
├── vite.config.js
└── package.json
```

## Установка и запуск

1. **Установите зависимости:**
```bash
cd dashboard
npm install
```

2. **Запустите dev сервер:**
```bash
npm run dev
```

3. **Откройте браузер:**
```
http://localhost:3001
```

## Функционал Dashboard

### 1. Hero Section
- Редактирование заголовка, подзаголовка, описания
- Настройка CTA кнопок
- Управление статистическими бейджами

### 2. About / Members
- Редактирование информации о бэнде
- Добавление/редактирование/удаление участников
- Управление фото участников

### 3. Events
- Полное CRUD управление событиями
- Настройка дат, мест, цен
- Управление статусом (доступно/продано)

### 4. Music
- Управление YouTube видео
- Управление альбомами
- Настройка ссылок на стриминговые сервисы

### 5. Gallery
- Добавление/редактирование/удаление изображений
- Категоризация изображений
- Управление метаданными (views, likes)

### 6. Statistics
- Редактирование статистических данных
- События, зрители, годы, альбомы

### 7. Booking Settings
- Включение/выключение формы бронирования
- Настройка параметров формы

## Хранение данных

В текущей версии данные сохраняются в **localStorage** браузера.

### Для production рекомендуется:

1. **REST API** - создать backend API для сохранения данных
2. **Firebase/Supabase** - использовать готовые BaaS решения
3. **База данных** - MongoDB, PostgreSQL и т.д.

### Пример интеграции с API:

Измените файл `src/stores/content.js`:

```javascript
// Вместо localStorage используйте API
const saveContent = async (section, data) => {
  try {
    const response = await axios.post('/api/content', {
      section,
      data
    })
    return true
  } catch (err) {
    error.value = err.message
    return false
  }
}
```

## Интеграция с основным сайтом

Для использования данных из Dashboard на основном React сайте:

### Вариант 1: Общий API
1. Создайте REST API
2. Dashboard сохраняет данные в API
3. React сайт читает данные из API

### Вариант 2: Общее хранилище
1. Используйте Firebase/Supabase
2. Оба приложения подключаются к одному хранилищу

### Вариант 3: Экспорт/Импорт
1. Dashboard экспортирует данные в JSON
2. React сайт импортирует JSON при сборке
