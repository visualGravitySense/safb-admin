# Исправление конфликта переменных окружения Vercel

## ✅ Проверка файлов завершена

Проверено в проекте:
- ✅ `now.json` - не найден (OK)
- ✅ `.nowignore` - не найден (OK)  
- ✅ `.now/` - не найден (OK)

**Вывод:** Проблема скорее всего в **переменных окружения** в Vercel Dashboard.

## 🔧 Решение: Проверьте переменные окружения

### Шаг 1: Откройте Vercel Dashboard

1. Зайдите на [vercel.com](https://vercel.com/dashboard)
2. Войдите в аккаунт
3. Откройте проект **`safb-admin`**

### Шаг 2: Проверьте Environment Variables

1. В проекте перейдите в **Settings → Environment Variables**
2. Просмотрите все переменные окружения

### Шаг 3: Найдите и удалите переменные с префиксом `NOW_`

Ищите переменные, которые начинаются с `NOW_`, например:
- ❌ `NOW_ENV`
- ❌ `NOW_URL`
- ❌ `NOW_REGION`
- ❌ Любые другие с префиксом `NOW_`

**Действие:** Удалите все переменные с префиксом `NOW_`

### Шаг 4: Используйте только переменные с префиксом `VERCEL_`

Если нужны переменные окружения, используйте префикс `VERCEL_`:
- ✅ `VERCEL_ENV` (если нужна)
- ✅ `VERCEL_URL` (устанавливается автоматически)
- ✅ `VERCEL_REGION` (устанавливается автоматически)

**Важно:** Vercel автоматически устанавливает переменные `VERCEL_*`, их не нужно добавлять вручную.

### Шаг 5: Передеплойте проект

После удаления переменных `NOW_`:

1. **Автоматически** - сделайте новый commit и push:
   ```bash
   cd dashboard
   git add .
   git commit -m "Fix Vercel environment variables"
   git push
   ```

2. **Или вручную** - в Vercel Dashboard:
   - Откройте последний деплой
   - Нажмите "Redeploy"

## ⚠️ Если переменных `NOW_` нет

Если в Environment Variables нет переменных с префиксом `NOW_`, но ошибка сохраняется:

1. **Проверьте Build Logs:**
   - Откройте последний деплой в Vercel
   - Посмотрите Build Logs
   - Найдите точное сообщение об ошибке

2. **Очистите кэш:**
   - Settings → General
   - Прокрутите до "Danger Zone"
   - Нажмите "Clear Build Cache" (если доступно)

3. **Создайте новый проект:**
   - Создайте новый проект в Vercel
   - Назовите его `safb-api`
   - Укажите Root Directory: `dashboard`
   - Деплойте заново
