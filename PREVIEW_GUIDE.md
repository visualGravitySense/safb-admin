# Руководство по предпросмотру изменений

## Обзор

Dashboard теперь поддерживает предпросмотр изменений в реальном времени. Вы можете видеть, как будут выглядеть изменения на сайте перед их сохранением.

## Как использовать

### 1. Открыть предпросмотр

1. Нажмите кнопку **"Preview"** в верхней панели Dashboard
2. Откроется страница предпросмотра с iframe, показывающим React сайт
3. Изменения в формах автоматически отображаются в предпросмотре

### 2. Режим предпросмотра

- **Автоматическое обновление**: Предпросмотр обновляется каждые 2 секунды
- **Реальное время**: Изменения в формах сразу видны в предпросмотре
- **Несохраненные изменения**: Предпросмотр показывает текущее состояние данных, даже если они еще не сохранены

### 3. Управление предпросмотром

- **Close Preview** - закрыть предпросмотр и вернуться в Dashboard
- **Open in New Tab** - открыть предпросмотр в новой вкладке браузера
- **Refresh** - обновить предпросмотр вручную

## Технические детали

### Как это работает

1. Dashboard сохраняет текущее состояние контента в `localStorage` с ключом `saf_content_preview`
2. React сайт проверяет наличие параметра `?preview=true` в URL
3. Если режим предпросмотра активен, React сайт загружает данные из `localStorage` вместо API
4. Данные обновляются каждые 2 секунды и при изменении контента

### Настройка URL React сайта

По умолчанию используется `http://localhost:5173`. Чтобы изменить URL, создайте файл `.env` в папке `dashboard`:

```env
VITE_REACT_SITE_URL=http://localhost:5173
```

Для production:
```env
VITE_REACT_SITE_URL=https://your-react-site.com
```

## Ограничения

1. **Изображения**: Загруженные изображения должны быть сохранены перед предпросмотром
2. **CORS**: Если React сайт на другом домене, могут быть проблемы с CORS
3. **Производительность**: Частые обновления могут замедлить работу

## Устранение проблем

### Предпросмотр не обновляется

1. Убедитесь, что React сайт запущен
2. Проверьте URL в `.env` файле
3. Откройте консоль браузера для проверки ошибок
4. Попробуйте нажать "Refresh"

### Предпросмотр показывает старые данные

1. Нажмите "Refresh" для принудительного обновления
2. Проверьте, что данные сохранены в формах
3. Очистите `localStorage` и попробуйте снова

### CORS ошибки

Если React сайт на другом домене:
1. Настройте CORS на React сайте
2. Или используйте прокси в Vite конфигурации

## Примеры использования

### Предпросмотр перед сохранением

1. Откройте любую секцию (Hero, About, Events и т.д.)
2. Внесите изменения в форму
3. Нажмите "Preview" для просмотра изменений
4. Если все хорошо, вернитесь и нажмите "Save"

### Сравнение изменений

1. Откройте предпросмотр
2. Откройте его в новой вкладке ("Open in New Tab")
3. Сравните текущую версию сайта с предпросмотром
